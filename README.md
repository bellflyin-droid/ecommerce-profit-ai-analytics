## 🤖 Agent职责说明

### 1️⃣ 数据归集Agent
- 多平台数据接入，AI智能表头匹配
- 数据清洗：去重、缺失值处理、格式转换
- 输出：标准化后的五张基础表 + 数据质量报告

### 2️⃣ 利润核算Agent
- 按财务规则完成SKU维度全流程利润核算
  - 销售收入确认 → 退款冲减 → 商品成本匹配 → 费用分摊 → 净利润计算
- 支持用户配置分摊规则（平台服务费、固定费用、广告费分摊方式可配置）
- 输出：SKU/平台/渠道各维度利润表

### 3️⃣ 异常识别Agent
识别 **10种** 常见利润异常：

| 异常类型 | 优先级 | 说明 |
|---------|--------|------|
| 持续亏损SKU | 🔴 高 | 净利润<0且亏损超过阈值 |
| 广告吞噬利润 | 🔴 高 | 广告费用超过毛利 |
| 高销售低毛利 | 🔴 高 | 大销量但毛利率<5% |
| 高退款率 | 🟡 中 | 退款占比超过15% |
| 边际贡献为正但会计亏损 | 🟡 中 | 账面亏损但实际贡献正边际 |
| 库存积压占用资金 | 🟡 中 | 周转天数超过90天 |
| 活动商品无盈利 | 🟡 中 | 活动亏本且未带动关联销售 |
| 物流成本异常 | 🟢 低 | 物流成本占比超过20% |
| 退款双重物流损失 | 🟢 低 | 退一件货承担双向运费 |
| 固定费用分摊伪亏损 | 🟢 低 | 分摊规则导致假性亏损 |

### 4️⃣ 经营建议Agent
基于异常识别结果，生成 **具体可执行+带预期收益测算** 的优化建议：

- 🔴 **高优先级**：清退建议、调价建议、广告裁剪建议
- 🟡 **中优先级**：库存清仓建议、活动复盘建议、详情页优化建议、保留观察建议
- 🟢 **低优先级**：物流方案优化、退款流程优化、分摊规则调整

### 5️⃣ 管理层问答Agent
- 接收自然语言问题，基于数据直接给结论
- 支持汇总查询、明细查询、对比分析、原因解释
- 只回答已有数据，不编造信息

## 💡 设计思路

作为**财务背景的AI产品经理**，这个项目的设计亮点：

1. **财务逻辑专业准确** - 利润核算规则、异常识别都是从实际财务工作经验中总结出来，不是凭空设计
2. **Agent分工合理** - 每个Agent只做一件事，符合单一职责原则，便于后续迭代扩展
3. **以决策为中心** - 不是为了做报表而做报表，最终目标是帮助管理者更快更好做决策
4. **可配置性** - 不同卖家核算习惯不同，关键规则允许用户配置，适应性更强
